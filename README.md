# 50 - Music Streaming Platform Discovery (AuraSound)

An underground electronic, ambient, and lofi discovery streaming platform built with React 18, Vite, Tailwind CSS, and Zustand.

## Features
- **Sonic Radar Discovery**: Large album-art grid with BPM tags, harmonic key classifications, and genre filtering.
- **Audio Transport & Scrub Bar**: Persistent bottom player with interactive scrub tracking, volume controls, and playback flow.
- **Curated Playlists & Mixes**: Algorithmic soundscapes and community-curated audio journeys.
- **Underground Artist Hub**: Artist profiles with unreleased tracks and follow synchronization.
- **Offline Cached Vault**: Client-side offline download simulation for zero-latency streaming.
- **Deep-Purple Gradient Theme**: Atmospheric nocturnal UI with Syne and Plus Jakarta Sans typography.

## Run Locally
```bash
npm install
npm run dev
```
Runs on port `3050`.
